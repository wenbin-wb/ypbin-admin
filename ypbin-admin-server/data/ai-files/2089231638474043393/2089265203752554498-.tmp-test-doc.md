# ypbin 平台使用指南

## 登录与账号
ypbin 管理平台使用 admin 账号登录，默认密码由管理员配置。登录后进入概览页。
平台采用 Sa-Token 认证，token 有效期 30 天，支持自动续期。

## AI 知识库
AI 知识库支持上传 PDF、Markdown、TXT 文档，系统自动解析并切片向量化。
向量化后即可进行语义检索和 AI 问答，问答会引用知识库中的原文片段作为依据。

## 模型配置
AI 配置页分为"对话模型"和"向量化模型"两个标签页。
对话模型用于 AI 对话与问答生成；向量化模型（如 text-embedding-v3）用于文档嵌入。
向量化模型通过阿里云百炼等 OpenAI 兼容接口接入，需配置 API Key。

## 部署架构
后端基于 Spring Boot 3 + ypbin-starter 自研底座，前端基于 Vue 3 + vben 模板。
数据存储使用 MySQL，缓存使用 Redis，支持多租户隔离。
