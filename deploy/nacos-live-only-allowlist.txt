# Nacos「live-only 键」白名单（issue #304）
#
# 背景：`deploy/install.sh` 把 deploy/nacos/*.yaml **整份**导入 Nacos（覆盖语义）。
# 任何「只存在于线上 live 配置、没进模板」的键，都会被这次覆盖**静默删除**。
# 已有两次真实事故（最严重的一次是 auth 的 identity.enabled 被删 → 平台无法登录）。
#
# install.sh 在每次 POST 之前会：
#   1) GET 线上当前配置；
#   2) 与「渲染后的待导入内容」逐**叶子键**比对；
#   3) 列出「线上有、模板无」且**不在此文件**里的键 → 告警（NACOS_IMPORT_STRICT=1 时直接失败）。
#
# 用法：每行一个**叶子键路径**（点分），`#` 起为注释。**必须写明理由**，否则下一个人无法判断能否删。
# 优先做法永远是「把键补进模板」；只有确实无法进模板（例如与具体机器绑定、或值只能由运行时决定）
# 才登记到这里。
#
# 示例（当前无此类键，故为空）：
# ypbin.xxx.some-machine-specific-key    # 理由：该值绑定单机网络配置，模板里无法表达
